# FairyGUI MCP 架构

## 模块边界

OpenFairyGUI core 负责原生模型、共享编辑 Schema、ID、引用图、XML 与序列化。
functions 负责不可变工程快照、混合编辑预演、语义回读和内存预览产物。
FairyGUI-dom 负责运行时布局、受控时钟与无副作用状态读取。
Headless 负责六个 MCP 工具、工程和预览会话、原子文件事务、隔离执行器及定义分发。

四个 npm 包使用 SemVer 依赖，开发期通过 `pnpm-workspace.yaml` 链接。
构建后可用 `pnpm pack` 生成独立安装产物。运行版本从已安装包清单读取。

运行需要 Node.js 24；Windows 为开发和截图基线。浏览器安装命令为 `pnpm exec playwright install chromium`。
专用工作进程与 Playwright Chromium 执行 runtime-preview；宿主负责超时终止与资源释放。

## 工具与结果

`fairygui.project` 管理工程会话并报告 Skill 路径；`fairygui.query` 返回命名原生查询。
`fairygui.edit` 执行 apply/plan/commit；`fairygui.preview` 管理动态运行与截图。
`fairygui.validate` 做 quick/roundtrip/publish/full 检查；`fairygui.publish` 生成正式产物。

工具发现传输稳定的外层结构。深层属性、操作和配方定义随 Skill 按文件分发，输入仍使用相同 Schema 严格验证。
查询默认分页 50 项，完整属性需要 detail:full。命名项独立返回信封，写入批次原子执行。

## 编辑链路

编辑从磁盘捕获字节快照，模型在隔离副本中修改。原生操作与受控 XML 片段共享引用校验、受影响文件序列化和回读语义检查。
非目标文件不重写；模型保留的原始 XML 附加数据参与序列化。保真以结构化语义为准。

计划有效期 30 分钟，保存来源依赖指纹、预分配 ID、逐操作结果及不可变修改快照。
提交前再次比较来源文件与依赖，并为事务提供预期字节。来源变化返回 SOURCE_CONFLICT。
同一工程写请求顺序执行。requestId 的摘要及成功回执进入事务日志，重试不重复创建对象。

事务先准备目标旁临时文件，验证来源后逐个替换；失败时回滚，启动时恢复未完成事务。
其他进程可能观察到短暂的跨文件中间态，外部并发改写通过预期内容检查拒绝。
日志默认保存 7 天、每工程 1 GiB；恢复证据和未完成事务不按普通过期日志删除。

## 快照与预览

预览只读取来源快照中的字节。编译在独立内存模型中临时导出组件，固定产物按指纹及运行版本缓存。
每个会话有独立工作进程和浏览器环境，各包使用独立资源基址。
网络路由只提供快照及显式映射资源，导航、外部请求、下载和子窗口受到限制。

默认手动时钟 60Hz、种子 0。时间线按输入顺序执行，再更新动画、刷新布局、读取属性并截图。
capture 与 inspect 不推进手动时间；截图采用固定画布。结果包含请求/实际时间、帧号、属性、诊断及运行版本。

run 带来源时临时执行，open 创建持续会话。reset 重建相同快照；reload 从最新工程捕获新快照。
持续会话最多两个、空闲 15 分钟回收。工程关闭时释放其预览和计划。
失败结果可保留已完成帧；失败会话可以检查、重置或关闭。

预算为每次 200 项编辑、64 帧、60 秒模拟时间、4096px 单边物理尺寸及 128 百万累计采样像素。
运行超时 30 秒、编译超时 120 秒，由宿主终止工作进程树。

## 定义与验证

Skill 提供工作流和按需文件导航，authoring 定义从共享 Schema 生成，runtime 类型来自 FairyGUI-dom 构建声明。
接口测试覆盖六工具发现、参数验证、计划预览、原子提交、图片分离、会话回收和 stdio 通道。
底层单元测试独立验证模型、引用、事务、快照与时钟语义。

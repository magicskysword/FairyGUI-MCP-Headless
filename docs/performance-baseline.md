# FairyGUI-unity 性能基线

本文件记录软性能预算，不作为提交硬门禁。通过以下命令在固定
`FairyGUI-unity/UIProject` 语料上重新采样：

```sh
pnpm benchmark:corpus
```

基准脚本只读取原始语料；基础 patch 在临时副本上执行，并比较运行前后的
源文件摘要。可用 `FAIRYGUI_UNITY_PROJECT` 指定其他语料路径，用
`FAIRYGUI_BENCHMARK_ITERATIONS` 调整热态采样次数。
